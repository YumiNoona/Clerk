# Clerk

Clerk is a first-person store simulator built with Unity 6.

The current prototype includes player interaction, held stock and boxes, shelf
stocking, product pricing, furniture purchasing and placement, an economy
foundation, and the visual/navigation foundation for customers.

## Project direction

The next playable milestone is the complete customer loop:

`spawn -> enter -> shop -> queue -> checkout -> pay -> exit`

The project architecture, module boundaries, migration order, and coding rules
are documented in [Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md).

## Unity version

Unity `6000.5.5f1`
